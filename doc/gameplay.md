# How the game plays

Rules that apply across the whole game. Rules for one place are in that place's file in [zones/](zones/).

- CHANGED: You don't choose your character. Instead, the character changes based on the scene: you play each scene as one of the kids, as they take place in the story, and the protagonist for that scene is chosen for you.
- (Earlier idea, now replaced: choose a kid at the start, and pick a different kid when you play again.)
- Gameplay feel: point-and-click where you move your character around, like Day of the Tentacle or Mystery of Woolie Mountain.
- Structure idea (Dandy): the game is made in chapters, like Kentucky Route Zero.
- Art style idea (Dandy, still exploring): characters and settings as low-res 3D models, like early PlayStation or N64.
- Voices: each character has their own voice (what each one sounds like: not decided yet). Dandy: the voices are stilted and overlap each other; they should speak a little slower and not overlap or cut each other off.
- Abilities are never the automatic first action (Dandy): for example, when May clicks an object, she shouldn't try to float it first. Instead, give an option to float it if the player wants to. This applies everywhere, not just the ping-pong scene.
- Hints (Dandy): leave subtle hints about things like this (for example, hinting that the squeegee can fish out the stone).
- Art style idea (Dandy, still exploring): a mix of low-bit pixel art and 3D like PlayStation 1 graphics. Options discussed: (1) kids' drawings as pixel cutouts in low-poly 3D rooms, (2) low-poly 3D characters using the drawings as textures, (3) a mix: 3D places and vehicles, flat pixel-cutout characters (my suggestion). Not decided; a test room was suggested.
- Consistent backgrounds (Dandy): make the backgrounds consistent; turn the drawings into the same format as the other stuff, so the kids' room drawings (like May's and Jasin's rooms) match the style of the rest of the game's scenes. (For the next game update.)
- Going back to places (Dandy, 2026-11-08): when the kids return to a place they've already been, show different text, so the story doesn't repeat. The first visit tells the story; later visits get shorter, new lines (for example, a quick "We've been here before" comment, or something that changed since last time).
- Debug menu: "after" versions of places (Dandy, 2026-11-08): the debug menu should let you jump to the second state of a place, not just the first visit. For example, go straight to the ping-pong mountain after the ping-pong guy is defeated, to see what it's like to be there then. Every place that changes after its puzzle or fight should have its "after" version in the debug menu.
- Buffer scenes (Dandy, 2026-11-08): add short in-between scenes around the big places, so the kids travel between them instead of just appearing. For example: going up the mountain before the ping-pong fight, and going down the mountain after it (see [zones/03-ping-pong-mountain.md](zones/03-ping-pong-mountain.md)).
- Flat skin (Dandy, 2026-11-08): make a skin for the whole game in the style of the first, flat version (`game/manor-konsz-game.html`, the 2D point-and-click), so the game can be played in that look as well as the PS1 3D look. Decisions (Dandy, 2026-11-08): flat 2D scenes like the first version (the kids' drawings, flat cartoon art where needed), kids walk across as cutouts, same story/items/save; start with the ship (chapter 1, every room has a kids' drawing), then add chapters one at a time; a button switches between Flat and 3D at any moment, same saved game. Still open: what undrawn places (after the crash) show in the flat look.
